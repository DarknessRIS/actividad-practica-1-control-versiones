## 1. Descripción

Proyecto web introductorio para practicar la organización de archivos y el control de versiones. La página utiliza HTML semántico, CSS adaptable y JavaScript básico. Incluye navegación por secciones, cambio entre tema claro y oscuro y una interacción sencilla.

El proyecto se preparó como alternativa porque no se aportó el proyecto HTML de la práctica anterior que menciona la orientación. Por tanto, no debe presentarse como si fuera aquel proyecto original.

## 2. Estructura

- `index.html`: contenido y estructura semántica.
- `styles.css`: presentación visual y adaptación a distintos tamaños de pantalla.
- `script.js`: cambio de tema, mensaje interactivo y actualización automática del año.
- `.gitignore`: exclusión de archivos temporales habituales.
- `GUIA_GIT.md`: explicación y comandos del flujo básico de Git y GitHub.

## 3. Cómo visualizarlo

Abre `index.html` en un navegador moderno. El proyecto no requiere dependencias externas ni un servidor para su visualización básica.

## 5. Distinción importante: Git y GitHub

- **Git local:** registra el historial de versiones en un repositorio de trabajo mediante `git init`, `git add` y `git commit`.
- **GitHub:** aloja una copia remota del repositorio y permite compartirla.
- **`git push`:** envía al repositorio remoto los commits existentes en el repositorio local.

La carga de archivos desde la web de GitHub puede crear un commit remoto y publicar el contenido, pero no demuestra por sí sola que Git se haya instalado, configurado y ejecutado localmente, ni que se haya ejecutado `git push`.
