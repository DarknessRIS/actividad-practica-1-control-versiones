## 1. Descripción

Proyecto web introductorio para practicar la organización de archivos y el control de versiones. Utiliza HTML semántico, CSS adaptable y JavaScript básico. Incluye navegación por secciones, cambio entre tema claro y oscuro y una interacción sencilla.

El proyecto se preparó como alternativa porque no se aportó el proyecto HTML de la práctica anterior mencionado en la orientación docente. Por tanto, no debe presentarse como si fuera aquel proyecto original.

## 2. Estructura

- `index.html`: contenido y estructura semántica.
- `styles.css`: presentación visual y adaptación a distintos tamaños de pantalla.
- `script.js`: interacciones y comportamiento de la página.
- `.gitignore`: exclusión de archivos temporales habituales.
- `GUIA_GIT.md`: explicación del flujo básico de Git y GitHub.

## 3. Cómo visualizarlo

Abre `index.html` en un navegador moderno. El proyecto no requiere dependencias externas ni un servidor para su visualización básica.

## 5. Diferencia entre Git y GitHub

- **Git local:** registra el historial de versiones en un repositorio de trabajo mediante operaciones como `git init`, `git add` y `git commit`.
- **GitHub:** aloja repositorios en línea y permite compartirlos.
- **`git push`:** envía los commits locales al repositorio remoto.

La carga mediante la interfaz web de GitHub crea un commit remoto. Sin embargo, no demuestra por sí sola que se hayan ejecutado localmente `git init`, `git add`, `git commit` ni `git push`.
