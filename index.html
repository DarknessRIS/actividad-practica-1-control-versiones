03 / APRENDIZAJE

Un proyecto, varias versiones

El control de versiones permite registrar cambios, consultar el historial y recuperar estados anteriores. Git gestiona ese historial; GitHub aloja repositorios en línea y facilita compartirlos.

Objetivo de la práctica

Preparar un proyecto web, organizar sus archivos y publicarlo en un repositorio remoto para practicar el flujo básico de control de versiones. Esta es la primera actividad práctica del Tema 1; el Seminario 1 fue la primera actividad evaluativa general.
